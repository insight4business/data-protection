# Dlp

**Purpose.** Templates for when you are designing, rolling out or operating data loss prevention.

**When to use.** You are designing, rolling out or operating data loss prevention.

| File | Description |
|---|---|
| dlp-exception-request.csv | Exception register for DLP policies |
| dlp-incident-playbook.md | Triage, containment and closure for DLP incidents |
| dlp-policy-catalog.csv | DLP policies for endpoint, email, collaboration and cloud |
| dlp-rollout-plan.md | Phased labeling and DLP rollout |
| pii-detection-patterns.csv | Example sensitive-data detection patterns and validation |
